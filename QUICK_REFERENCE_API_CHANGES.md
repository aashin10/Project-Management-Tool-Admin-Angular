## 🚀 Quick Start

### Before (OLD)

```typescript
// ❌ OLD - Don't use this anymore
import * as bcrypt from 'bcryptjs';

// Fetch users
this.usersApi.getUsers().subscribe((users) => {
  console.log(users);
});

// Create user
const passwordHash = bcrypt.hashSync('Doe@experionglobal.123', 10);
this.usersApi
  .createUser({
    name: 'John Doe',
    email: 'john@example.com',
    password_hash: passwordHash,
    avatar_url: 'https://avatar.iran.liara.run/username?username=John+Doe',
    is_super_admin: false,
    is_active: true,
    type: 'Internal',
    status: 'Active',
    created_by: 1,
  })
  .subscribe((response) => {
    console.log('Created:', response.data.name);
  });
```

### After (NEW)

```typescript
// ✅ NEW - Use this
import { CreateUserDto } from '../../services/users-api';

// Fetch all users
this.usersApi.getUsers().subscribe((users) => {
  console.log(users);
});

// Fetch filtered users
this.usersApi
  .getUsers({
    type: 'Internal',
    status: 'Active',
  })
  .subscribe((users) => {
    console.log(users);
  });

// Create user (backend handles password, avatar, defaults)
const userData: CreateUserDto = {
  name: 'John Doe',
  email: 'john@example.com',
  jiraId: 'JIRA-123', // Optional
  type: 'Internal', // Optional
  createdBy: 1, // Optional
};

this.usersApi.createUser(userData).subscribe((response) => {
  const createdUser = response.data[0]; // Note: data is now an array
  console.log('Created:', createdUser.name);
});
```

## 📋 API Method Changes

### getUsers()

| Aspect           | Before        | After                          |
| ---------------- | ------------- | ------------------------------ |
| **HTTP Method**  | GET           | POST                           |
| **Endpoint**     | `/api/User`   | `/api/User/filter`             |
| **Parameters**   | None          | `{ type?, status? }`           |
| **Request Body** | N/A           | `{ type: null, status: null }` |
| **Caching**      | Always cached | Only cached when no filters    |

**Examples:**

```typescript
// No filters - returns all users (cached)
this.usersApi.getUsers();

// Filter by type only
this.usersApi.getUsers({ type: 'Internal' });

// Filter by status only
this.usersApi.getUsers({ status: 'Active' });

// Filter by both
this.usersApi.getUsers({ type: 'Internal', status: 'Active' });
```

### createUser()

| Aspect               | Before                     | After                              |
| -------------------- | -------------------------- | ---------------------------------- |
| **Required Fields**  | 10 fields                  | 2 fields (name, email)             |
| **Optional Fields**  | 1 field (jira_id)          | 3 fields (jiraId, type, createdBy) |
| **Request Wrapping** | Direct object              | Wrapped in `users` array           |
| **Response**         | Single object              | Array of objects                   |
| **Frontend Handles** | Password, Avatar, Defaults | Nothing (backend handles all)      |

**Field Mapping:**

| Old Field Name   | New Field Name | Required | Generated By              |
| ---------------- | -------------- | -------- | ------------------------- |
| `name`           | `name`         | ✅ Yes   | Frontend                  |
| `email`          | `email`        | ✅ Yes   | Frontend                  |
| `jira_id`        | `jiraId`       | ❌ No    | Frontend                  |
| `type`           | `type`         | ❌ No    | Frontend                  |
| `status`         | ❌ Removed     | N/A      | Backend (always "Active") |
| `password_hash`  | ❌ Removed     | N/A      | Backend                   |
| `avatar_url`     | ❌ Removed     | N/A      | Backend                   |
| `is_super_admin` | ❌ Removed     | N/A      | Backend (always false)    |
| `is_active`      | ❌ Removed     | N/A      | Backend (always true)     |
| `created_by`     | `createdBy`    | ❌ No    | Frontend                  |

### createUsers() - NEW METHOD

```typescript
createUsers(users: CreateUserDto[]): Observable<CreateUserResponse>
```

**Usage:**

```typescript
const usersToCreate: CreateUserDto[] = [
  { name: 'User One', email: 'user1@example.com', type: 'Internal' },
  { name: 'User Two', email: 'user2@example.com', type: 'External' },
  { name: 'User Three', email: 'user3@example.com' },
];

this.usersApi.createUsers(usersToCreate).subscribe((response) => {
  console.log(`Created ${response.data.length} users`);
  console.log('Message:', response.message);

  // Handle partial success
  if (response.data.length < usersToCreate.length) {
    console.log('Some users failed:', response.message);
  }
});
```

interface GetAllUsersQuery {

## 🐛 Common Errors and Fixes

### Error: "Cannot find name 'CreateUserRequest'"

**Fix:** Use `CreateUserDto` instead

```typescript
// ❌ Before
const userData: CreateUserRequest = { ... };

// ✅ After
const userData: CreateUserDto = { ... };
```

### Error: "Property 'password_hash' does not exist"

**Fix:** Remove password_hash - backend generates it

```typescript
// ❌ Before
const userData = {
  name: 'John Doe',
  email: 'john@example.com',
  password_hash: bcrypt.hashSync('...', 10), // Remove this
};

// ✅ After
const userData: CreateUserDto = {
  name: 'John Doe',
  email: 'john@example.com',
};
```

### Error: "Type 'ApiUser' is not assignable to type 'ApiUser[]'"

**Fix:** Response data is now an array

```typescript
// ❌ Before
next: (response) => {
  const user = response.data; // Single object
};

// ✅ After
next: (response) => {
  const user = response.data[0]; // Array - get first item
};
```

### Error: "GET /api/User 404 Not Found"

**Fix:** Endpoint changed to POST /api/User/filter

```typescript
// ❌ Before
this.http.get<ApiResponse>(this.apiUrl);

// ✅ After
this.http.post<ApiResponse>(`${this.apiUrl}/filter`, filterBody);
```

## 📊 Field Auto-Generation by Backend

| Field              | Pattern                                                                  | Example                                                                 |
| ------------------ | ------------------------------------------------------------------------ | ----------------------------------------------------------------------- |
| **password_hash**  | `[lastname]@experionglobal.123`                                          | "John Doe" → `Doe@experionglobal.123`                                   |
| **avatar_url**     | `https://avatar.iran.liara.run/username?username=[firstname]+[lastname]` | "John Doe" → `https://avatar.iran.liara.run/username?username=John+Doe` |
| **is_super_admin** | Always `false`                                                           | `false`                                                                 |
| **is_active**      | Always `true`                                                            | `true`                                                                  |
| **status**         | Always "Active"                                                          | "Active"                                                                |
| **type**           | Normalized (capitalized)                                                 | "internal" → "Internal"                                                 |
